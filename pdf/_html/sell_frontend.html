Used to search the merchant catalog (PostgreSQL)

S1b · Parse → JSON → database search (the core)
  • The pipeline: customer text → LLM parses it → a structured JSON intent → validated → a real search over the merchant’s catalog (by category, price ≤ budget, active).
  • Safety: the JSON is untrusted and schema-checked; the search is parameterized; results use server-owned prices only. This same intent is hashed into the Transaction Passport for proof later.
